# MemeDime - MVP Specification

## 🎯 Core Concept

**What:** An app that generates AI-powered meme coin ideas for $0.10 per spin using x402 micropayments.

**Why:** First consumer application showcasing x402 protocol - demonstrating autonomous micropayments for AI services in a fun, viral way.

**Tagline:** "Pull the lever, launch a legend" 🎰

---

```
memedime.fun

💰 Only $0.10 per spin
⚡ Powered by x402 micropayments
```

## 📱 Key Interactions

### 1. Connect Wallet
**Trigger:** User clicks "Connect Wallet" button  
**Action:**
- Detect if Phantom installed
- If yes: Request connection
- If no: Show "Install Phantom" prompt with link
  **Success:** Show wallet address (truncated) and USDC balance  
  **Failure:** Show error message and retry button

### 2. Optional Context Input
**Trigger:** User types in context field (optional)  
**Behavior:**
- NOT required - can be left empty
- Placeholder text: "e.g., 'make it about gaming' or 'super aggressive marketing'"
- Character limit: 100 characters
- Persists between spins (sticky input)
- Clear button to reset
  **Examples shown on hover:**
- "themed like pirates"
- "wholesome and cute"
- "extremely sarcastic"
- "aimed at gamers"

### 3. Pull Lever
**Trigger:** User clicks "Pull Lever" button  
**Action:**
- Disable button (prevent double-click)
- Save context input if provided
- Animate reels spinning
- Randomly select 3 emojis
- Stop reels one by one (dramatic effect)
  **Result:** Show payment modal with selected combo + context

### 4. Payment Flow
**Trigger:** User clicks "Pay & Generate"  
**Modal shows:**
- Emoji combo
- User's context (if provided)
- Price: 0.01 USDC
  **Action:**
- Request USDC transaction via Phantom
- Amount: 0.01 USDC
- Recipient: Your wallet address
- Wait for confirmation
  **Success:** Show "Generating..." state  
  **Failure:** Show error, allow retry

### 5. Generation
**Trigger:** Payment confirmed  
**Action:**
- Call backend API with:
    - Emoji combo
    - Payment signature
    - User context (if provided)
- Backend calls Groq AI with enhanced prompt
- AI generates coin idea influenced by context
- Return JSON to frontend
  **Display:** Show complete coin card with all details

### 6. Share on Twitter
**Trigger:** User clicks "Tweet This"  
**Action:** Open Twitter with pre-filled text:
```
Just generated $[TICKER] on @memedime.fun! 🎰

[If context used: "Theme: [context]"]

"[First line of concept]"

Should I launch it? 👀

Try it: https://memedime.fun
```

### 7. Launch on Pump.fun
**Trigger:** User clicks "Launch on Pump.fun"  
**Action:**
- Show modal explaining process
- "This will cost ~0.02 SOL (~$5)"
- Button: "Continue to Pump.fun"
  **Next:** Open pump.fun in new tab with pre-filled data

### 8. Spin Again
**Trigger:** User clicks "Spin Again"  
**Action:**
- Return to slot machine view
- Context input persists (or can be changed)
- Ready for next spin
  **State:** Preserve stats (total spins, total spent)

## 🎨 Visual Style Guide

### Design Principles
1. **Fun first** - This is entertainment, not serious finance
2. **Casino aesthetic** - Vegas vibes, gold accents, dramatic
3. **Web3 native** - Purple gradients, glassmorphism, modern
4. **Clear CTAs** - Big buttons, obvious next steps
5. **Instant feedback** - Every action has visual response

### Color Usage
- **Purple gradient** - Primary background, main theme
- **Gold/Yellow** - Accents, highlights, success states
- **White** - Text, cards, clean contrast
- **Green** - Success, payments confirmed
- **Red** - Errors, warnings
- **Light gray** - Optional/secondary elements (like context input)

### Animation Guidelines
- **Reel spin** - 2-3 seconds, blur effect while moving
- **Lever pull** - Physical feedback, "clunk" feel
- **Result reveal** - Fade in, scale up slightly
- **Loading states** - Spinner or progress bar
- **Micro-interactions** - Hover states, button presses
- **Context hint** - Subtle pulse when empty to show it's optional

## 🔄 Edge Cases & Error Handling

### No Wallet Detected
**Show:** Large modal with Phantom logo  
**Message:** "You need Phantom wallet to play!"  
**Action:** [Install Phantom] button → opens phantom.app

### Insufficient Balance
**Show:** Warning before spin  
**Message:** "Your balance: 0.003 USDC. Need 0.01 USDC to spin."  
**Action:** [Add Funds] button → links to exchange/on-ramp

### Context Too Long
**Show:** Character counter turns red  
**Message:** "Max 100 characters. Be concise!"  
**Action:** Disable pull lever until under limit

### Inappropriate Context
**Show:** Warning after payment  
**Message:** "Your context violates our guidelines. Generating without it."  
**Action:** Proceed with combo only, refund not needed (already generating)

### Payment Rejected
**Show:** Error message  
**Message:** "Payment cancelled. No charge. Try again?"  
**Action:** [Try Again] button → returns to spin result

### Payment Pending
**Show:** Loading state  
**Message:** "Confirming payment... (~2 seconds)"  
**Action:** Wait for confirmation, then proceed

### AI Generation Failed
**Show:** Error message  
**Message:** "Oops! AI had a hiccup. Trying again..."  
**Action:** Auto-retry once, then show error + refund option

### Slow Network
**Show:** Extended loading state  
**Message:** "This is taking longer than usual... Still working!"  
**Action:** Keep trying, timeout after 30 seconds

## 💭 Why Optional Context Works

### Psychological Benefits

**1. Agency**
- Users feel in control
- Not just "random" - they influenced it
- More invested in the result

**2. Discovery**
- First spin: "Let me try without context"
- Second spin: "Wait, what if I add context?"
- Third+ spins: Experimenting with different contexts

**3. Mastery**
- Learning what contexts work best
- Sharing "pro tips" with others
- Becoming a memedime expert

**4. Replayability**
- Same combo = different results with contexts
- Reasons to come back
- Never gets boring

### Design Decisions

**Why Optional:**
- Don't force complexity on first-time users
- Progressive disclosure
- Casual users can ignore it
- Power users can master it

**Why Persistent:**
- Don't make users retype each time
- Encourages exploration with variations
- Can easily change between spins

**Why 100 Character Limit:**
- Forces conciseness
- Easier for AI to parse
- Prevents abuse/spam
- Keeps it simple

**Why Free-Form Text (Not Dropdown):**
- Infinite possibilities
- Encourages creativity
- Surprising combinations
- User-generated variety
